# Neon Step District

A legally distinct Dance Dance Revolution-inspired static browser game.

Open `index.html` directly in a browser, or append `?autoplay=1` to watch the hidden chart-timing verifier play the stage automatically.

## Controls

- `ArrowLeft`, `ArrowDown`, `ArrowUp`, `ArrowRight`: hit tap steps
- `Space`: pause or resume during a stage

## MVP Contract

- One complete 75-second arcade-trance stage
- Upward-scrolling four-lane tap-step chart
- `Perfect`, `Great`, `Good`, and `Miss` judgments
- Life bar, stage fail, retry, results, grade, judgment counts, max combo, and locally saved best result
- Dependency-free static HTML, CSS, and JavaScript
